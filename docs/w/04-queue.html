The queue

What one AQL compute queue is made of, and why the kernel makes it five separate allocations.

A queue is five buffers and one ioctl.

The kernel counts bytes. Each buffer must be the start of its own allocation, and the allocation size must equal the expected size exactly. So we make five separate ALLOC calls, each sized to the byte, plus a doorbell page.

The five buffers:

  1. The ring holds the packets. Every slot starts with the header for INVALID, so a half-written packet never runs.
  2. The write pointer gets its own page. Our code advances it.
  3. The read pointer gets its own page. The hardware advances it as packets retire.
  4. The CWSR area is the context save area. Its size comes from the sysfs node properties.
  5. The EOP buffer is optional to the ioctl and required by the hardware. Without it, the first REMOVE_QUEUE hangs MES and resets the GPU.

The doorbell is the contract.

CREATE_QUEUE returns an offset. The high bits name a doorbell page. The low bits name this queue's u64 inside that page. Writing the packet index there starts the hardware.

The CP also polls the write pointer while memory is coherent, so a packet can run without a doorbell write. Ring it anyway.
