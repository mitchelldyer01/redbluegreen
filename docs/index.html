redbluegreen wiki

A GPU training toolchain for one machine, written down so the reasoning survives.

redbluegreen is a GPU training toolchain for the AMD Strix Halo APU. We build it from the kernel interface up with no GPU userspace under it.

The seven layers, in dependency order:

  1. kfd and queue
  2. memory
  3. kernels
  4. autograd
  5. optimizer
  6. loop
  7. data resident in GPU memory

Each layer uses only the layer below it. Nothing above layer 3 exists yet.

The units so far:

  1. Talk to the driver: GET_VERSION and ACQUIRE_VM.
  2. Own memory: ALLOC, MAP and a host view.
  3. Own the queue: Drop types, an AQL queue and an event.
  4. Dispatch one kernel that writes 42.
  5. Add two vectors at 225 GB/s.

The toolchain has zero external dependencies at run time. The build needs llvm-mc and llvm-objcopy to assemble kernels, and rustc. There are no crates.
